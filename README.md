# 贪吃蛇 · Snake

浏览器里可直接游玩的经典贪吃蛇小游戏：方向键 / WASD 控制，吃食物得分变长，撞墙或撞到自己结束。最高分保存在 `localStorage`。

## 本地运行

这是一个零依赖的静态页面，用任意静态服务器打开即可。

```bash
# 任选一种
python3 -m http.server 4173
# 或
npx --yes serve -l 4173
```

浏览器访问 [http://localhost:4173](http://localhost:4173)。

也可以直接打开 `index.html`，部分浏览器对本地文件限制较少时同样能玩。

## 操作

- 移动：方向键或 `W A S D`
- 重新开始：空格，或点击「重新开始」
- 暂停 / 继续：`P`，或点击「暂停」
- 手机：屏幕方向键，或在棋盘上滑动

## 文件

- `index.html` — 页面结构
- `styles.css` — 深色主题样式
- `game.js` — 游戏逻辑与绘制
